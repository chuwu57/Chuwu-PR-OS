# Principle: PR Lowers Trust Cost

## 规律

PR的经营价值不是替代销售，而是持续降低组织被理解、被相信、被选择和在危机中被允许解释的成本。

## 为什么成立

曝光、稿件数和榜单位置只能证明信息出现过，不能证明目标人群形成了正确理解。稳定的媒体关系、清楚的话语体系、可搜索的事实、长期一致的行动和快速响应机制，会让业务在新品、合作、招聘、融资和危机中减少重复解释与信任折损。

## 改变的行动

PR评估至少观察：

1.关键人群能否准确复述品牌是谁、解决什么问题。
2.第三方内容是否被销售、客服、招聘或合作场景复用。
3.搜索、社区和AI摘要是否形成稳定且准确的信息面。
4.危机发现、决策和回应时间是否缩短。
5.相同事实需要付出的解释成本是否下降。

短期转化可以作为辅助信号，但不能吞掉全部PR价值。

## 服务承诺要提供使用与纠错路径

公众需要能够判断：谁可获得什么服务、何时和怎样进入、由谁负责、未兑现时如何反馈并得到结果。规则模糊会把解释和协调成本转给顾客；赠礼与会员礼遇同样会形成服务预期，金额低不能自动消除关系责任。

平凉的延时服务公开规则提供清单、预约与反馈设计的参照，尚无独立服务效果。Tiffany礼赠纠纷的原始采访则提示，服务失约后的异常联络与隐私处理可能成为新的争议对象；报道确认品牌致歉与整改承诺，具体交易和沟通仍有当事人陈述边界。两者只能支持检查设计与风险，不能被用作「机制已提高信任」的结果证明。

迁移到客服、维修或会员权益时，将资格、进入路径、负责人、补救与反馈连起来，再检验办成率、等待时间、重复联系、问题复发和顾客体验。若公开规则与后台资源不匹配，解释越清晰也可能暴露更大的履约落差。

## 边界

「长期价值」不能成为拒绝评估的借口。每项PR动作仍需明确目标人群、预期认知变化、可观察信号和复盘期限。
