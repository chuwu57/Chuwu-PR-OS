# PR理论问题链

问题链不是新的万能理论，也不是操作清单。它从真实PR谜题出发，把传播学、心理学和社会学放到各自能够解释的层次，再说明这些解释如何衔接、竞争和互相限制。

学科总入口：[传播理论](../Communication/00_MOC/传播理论到PR判断.md)、[心理理论](../Psychology/00_MOC/心理理论到PR判断.md)、[社会理论](../Sociology/00_MOC/社会理论到PR判断.md)。问题链中的每个判断都应回到对应专论核对证据和边界。

## 使用原则

先确认当前事实，再沿问题链确定需要解释的层次。一次事件不必经过链上的所有环节；理论负责提出竞争解释，证据负责判断哪一条机制实际存在。问题链不能替代事实核验，也不能把复杂事件机械归入固定阶段。
