# Follow Loop增量知识工作流

## 任务

一次手动运行默认同时更新AI建设者、PR建设者与行业信号、Case Follow、具身智能和奢侈品五条线，并把结果写入各自知识位置。

## 输入

- 统一来源注册表、主题优先级和逐来源断点。
- AI与PR人物档案、PR信号雷达、Case Follow去重与开放复核状态、具身智能对象档案与雷达、奢侈品对象档案与雷达。
- 经过压缩的真实反馈，用于调整五条线的筛选、路由和证据门槛。
- 用户明确限定的人物、主题或时间窗；未限定时覆盖全部启用来源。

## 核心步骤

1.保存检查／状态基线、请求窗口与selected_source_ids；保留可定位的恢复manifest。
2.先维护到期的Case Follow方法复核。
3.覆盖本轮所选的全部启用来源；未限定范围时即全部。区分确定性扫描与best-effort搜索，范围外来源不变。
4.统一归一来源、人物、组织、日期、地区、主题和URL。
5.一次核验后路由到AI人物、PR人物／信号、Case候选、具身智能对象／信号或奢侈品对象／信号；允许形成跨线次级路由。
6.先写Evidence，再写人物、对象、趋势、雷达和案例状态。
7.先修复本轮资产预检失败，再最后写入成功来源State并用baseline＋manifest复验；成功水位等于实际覆盖终点且不倒退，失败／部分覆盖冻结。按检查基线区分无关旧问题；按manifest幂等恢复，不宣称只恢复State就撤销全部资产。

## 输出

- AI人物有效更新和命题演化。
- PR人物更新、行业信号、共识、分歧和阶段变化。
- Case Follow候选、方法命题、证据等级、适用边界和推荐动作。
- 具身智能对象演化、能力／部署信号和证据边界。
- 奢侈品对象演化、市场／品牌信号和证据边界。
- 完整运行聚合五条线；局部运行只展开所选范围，并明确未运行线。形成对中国消费品PR的影响、行动变化和知识缺口。

## 边界

- 精确自然语言入口为「启动Follow Loop，更新一下」和「FL一下」；不匹配单独的「FL」或「更新一下」。
- 不创建日期化资讯堆积，不自动创建定时任务。
- Case Follow候选在用户确认前只进入系统状态，不自动进入知识本体。
- 运行过程不进入人物、趋势、案例或Evidence正文。
