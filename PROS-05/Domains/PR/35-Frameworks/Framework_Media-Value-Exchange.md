# Framework: 媒介价值交换模型

用于处理预算受限、头部媒体独家、KOL 合作、付费买分暗示等媒介资源博弈。

## 核心判断

媒介合作不只是钱换曝光，而是多种价值之间的交换：

- 现金预算。
- 信息差：独家数据、未公开细节、研发洞察。
- 时间差：首发、提前体验、优先测试。
- 内容差：专访、纪录片、实验室探访、深度拆解。
- 关系差：长期信任、未来优先权、危机解释窗口。

## 使用方法

1. 先判断对方真正需要什么：流量、专业性、内容稀缺性、商业收入，还是行业地位。
2. 再判断品牌不能让渡什么：结论购买、核心机密、绝对独家、虚假背书。
3. 最后设计替代权益：用信息、内容、时间和关系替代单纯现金。

## 核心原则

买渠道可以，买结论不行。

PR 要维护的是长期信任网络，而不是一次传播的表面繁荣。


## 把媒体接触扩展为组织理解

初五01:41:36提出不以每次发稿为条件的业务开放交流；01:43:13—01:43:35则强调，让媒体接触研发、供应链等相关岗位的关键人物，减少关系只停留在公关或创始人个人联系上的局限。前者是方向性建议，后者包含个人实践自述；均未提供独立关系效果数据。

可迁移的判断是：按对方议题提供合适的业务人员、可核实材料和后续求证入口，再观察媒体是否理解了具体业务、愿意继续交流。交换微信、接触人数、行程密度或到场疲劳都不能单独证明关系变深；关系也不意味着对方必须支持企业结论。

15:42的采访协商自述提示，企业需要明确无法披露的内容，并提出可回答、有公共或报道价值的替代信息。应与媒体讨论相关性和采访范围，不能把「完成自己的传播目的」变成控制独立报道、回避实质责任或购买结论。关于产品问题与公共利益的必要追问，不能靠更换提纲消除；材料和业务事实决定可说范围。

执行合同继续沿用[全年媒体关系公关战略](../45-Workflows/Workflow_Annual-Media-Relations-Strategy.md)，此处只补充组织接触面与协商边界，不另建一套媒体SOP。
