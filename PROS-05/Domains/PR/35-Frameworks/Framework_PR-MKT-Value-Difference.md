# Framework: PR / MKT 价值差异框架

用于内部沟通时对齐任务、责任和评价方式。核心判断是：不能只用短期出量解释公关的全部价值，也不能以长期信任为由回避对结果的检验。

## 先区分任务，再确定部门分工

|任务侧重|需要改变什么|可以观察什么|
|---|---|---|
|组织信任、关系与声誉|特定公众怎样理解企业、判断其可信度，以及是否愿意继续沟通合作|事实理解、质疑主题、解释机会、关系反馈与纠偏落实|
|需求、选择与增长|目标用户是否理解产品价值，能否购买、使用并愿意再次选择|需求与价值认知、购买路径、转化、使用和复购表现|

PR常承担前一类任务，MKT常承担后一类任务，但实际组织可能交叉分工。品牌营销可以包含长期品牌建设，公关动作也可能帮助渠道、销售和用户选择；不能把两者固定切成长期与短期、公司与业务两个互不相干的领域。

因此先说明本项目主要想改变谁的什么判断或行为，再确定主责、协作和决策权限。部门名称本身不能证明某项工作应该由谁独占。

## 目标重叠时怎样分工

以一个假设的新品项目为例：如果用户不购买是因为不知道使用场景，团队需要检查产品价值表达与触达；如果用户已理解产品，却不相信承诺，还要核实承诺的依据、交付与可信解释；如果问题是买不到或售后无法履约，单纯增加投放或报道都无法直接补上交付缺口。

这些原因可以同时存在。公关、营销与业务应围绕原因分别承担任务，复用同一事实源；不能根据销售未增长就直接判定公关无效，也不能根据媒体报道增加就宣称问题已经解决。这是解释分工的假设场景，不是已验证的项目案例。

## 评价与资源取舍

按照[Framework_PR-Business-Contribution-Metrics](Framework_PR-Business-Contribution-Metrics.md)，投入前对齐职责、目标公众、预期变化和可观察结果。曝光、点击、工时与稿件数量可以描述投入或过程，但不能单独替代理解、信任、选择与经营结果。

短期转化任务可以重视可核验的转化与成本；长期品牌、关系和声誉任务需要匹配观察窗口与证据。销售同时受产品、价格、供货、渠道等条件影响，缺少对照或足够识别时，只报告可支持的贡献与同步变化，不声称确定的增量收入或避免损失。

预算比较要回到业务瓶颈：增加资源能改变哪个条件，其他团队是否有能力承接，放弃该动作会承担什么代价。任何团队都不能只凭「长期」「战略」或「ROI」标签获得资源，也不应被迫用无法验证的数字自证。

## 使用边界

这是一套任务与评价的对齐方法，基于已归档的公关实务及库内指标框架，不是对所有企业部门职责的经验定律。小团队可能由同一岗位承担多种任务，成熟组织也可能采用不同分工；以实际授权和交付责任为准。指标变化还须回看事实和受影响者经验，避免漂亮数字掩盖未解决的问题。
