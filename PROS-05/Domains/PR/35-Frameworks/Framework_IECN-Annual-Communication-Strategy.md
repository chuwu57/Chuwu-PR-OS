# Framework: IECN 年度传播策略模型

用于写年度 PR / 传播策略前的先行判断。

## I — Industry

行业特点。

关键问题：

- 这个行业的消费者最关心什么？
- 行业底线是什么？
- 行业当前最大的舆论压力来自哪里？

## E — Ecosystem

竞争格局。

关键问题：

- 竞品主要打法是什么？
- 竞品强项和弱点在哪里？
- 行业舆论目前倾向哪边？

## C — Core

品牌本质。

关键问题：

- 我们现在是谁？
- 我们从哪里来？
- 我们现阶段需要曝光、口碑、信任、品类教育，还是风险修复？

## N — Narrative

叙事要求。

关键问题：

- 要对谁说？
- 说什么？
- 用什么话术和载体？
- To B 与 To C 是否需要拆开叙事？
