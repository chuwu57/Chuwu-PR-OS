# Framework: CRI / 5R 危机判断矩阵

用于同时判断「危机有多大」与「处置有多有效」。

## CRI：危机风险指数

观察维度：

- 舆情热度。
- 传播速度。
- 国际扩散。
- 情绪强度。
- 商业影响。
- 回应失败程度。

判断重点：

- CRI 高不代表企业一定处置差，可能只是事件触及的价值、情绪或商业影响很深。
- 回应失败本身会反向推高 CRI，因为糟糕处置会制造二次危机。

## 5R：处置质量

观察维度：

- 响应速度。
- 担责。
- 共情。
- 纠偏行动。
- 透明可信。

判断重点：

- 速度是入场券，不是分水岭。
- 真正拉开差距的是担责、共情、纠偏和透明。
- 高 CRI + 高 5R 是「危机大但处置有效」；高 CRI + 低 5R 是「声誉损耗最重」。

## 使用方法

面对危机时先分两步：

1. 用 CRI 判断事件本身的烈度与破圈可能。
2. 用 5R 判断组织回应是否正在降低还是放大风险。
