# Framework: 舆论事件的格式判断与响应框架

## 用途

用于判断舆论事件为什么扩散、公众实际在审判什么，以及品牌应该用什么结构回应。

这个框架特别适合处理截图爆料、长文爆料、PDF、PPT、短视频切片、评论区高赞负面、群聊记录、投诉平台截图等「证据型传播」。

核心判断：舆论不是事实本身的自然扩散，而是事实、媒介格式、平台机制、群体身份和道德情绪共同生产出来的公共判断场。

---

# 0.先还原公众实际看见的现实

组织掌握的完整事实，不等于公众能够接触到的事实。进入五层分析前，先完成「拟态环境还原」：

| 层级 | 要回答的问题 | 输出 |
|---|---|---|
| 现实事实 | 内部确认发生了什么 | 已确认、待核实、存在争议的事实清单 |
| 可见事实 | 公众当前能够看到什么 | 外部材料和信息缺口 |
| 媒介版本 | 标题、截图、切片、热评如何组织材料 | 最高传播版本及其叙事结构 |
| 头脑图像 | 公众把品牌想象成什么角色 | 最强角色标签和道德判断 |
| 修正路径 | 应补事实、改框架还是补信任 | 回应材料、渠道、负责人和验证动作 |

还原时至少检查传播起点、最高传播版本、搜索结果、评论区共识、可复制攻击句式，以及支持品牌的人为什么难以开口。

合格输出必须说明：公众现在看到的版本是什么、它由哪些材料拼成、哪些属于事实缺失或框架错位、品牌准备补什么材料，以及媒体、用户和AI搜索最终应能引用哪一句事实。

---

# 1. 舆论事件五层模型

任何舆论事件都不要只看「发生了什么」，而要拆成五层：

## 事实层

事实层回答：

- 到底发生了什么？
- 哪些信息已经被证实？
- 哪些只是单方说法？
- 哪些细节会影响责任归属？

PR 风险：

如果品牌只在事实层回应，但公众真正愤怒的是价值层或身份层，回应会显得冷漠、傲慢或避重就轻。

## 格式层

格式层回答：

- 信息以什么形式出现？
- 是聊天截图、PDF、PPT、短视频、直播切片、长文、录音、检测报告，还是评论区二创？
- 这种格式可能提供哪些可信度或完整性感知线索？

常见格式线索：

- 聊天记录可能提供私密性、现场感和反转空间线索。
- PDF可能提供完整性、正式感和证据感线索。
- PPT可能提供汇报感、议程组织和要点化结论。
- 短视频切片可能提高情绪与冲突线索的可见性，也更容易丢失上下文。
- 蓝底白字或平台公告可能提供权威线索，也可能显得机械。
- 长音频或深度访谈可以承载复杂解释，但未必适合需要快速风险告知的场景。

这些不是稳定的「格式效应」。实际结果受信源、内容完整性、受众经验、平台语境和既有信任调节，必须用当前传播数据核验。

PR 风险：

高度结构化或强现场感的材料可能让部分受众更快形成「已经看懂」的判断，但这也可能只是材料组织提供的理解线索，不能替代事实核验。

## 平台层

平台层回答：

- 当前可观察的分发结果中，哪些表达获得更高可见性？能否由排序、推荐或传播路径数据支持？
- 是愤怒、反转、玩梗、二创、阴谋论、事实核查，还是受害者叙事？
- 哪些账号、社群、KOL、营销号会继续加工事件？

PR 风险：

品牌不能假设外部受众看到的是完整事实，也不能无数据声称「多数人」看到某个版本。研判对象应限定为当前可观察的高可见版本，并说明样本、平台和时间窗。

## 身份层

身份层回答：

- 谁会觉得这件事「和我有关」？
- 消费者、员工、女性、打工人、粉丝、行业从业者、地方身份群体，分别会被什么触发？
- 事件是否让某些群体感到被轻视、被欺骗、被冒犯或被背叛？

PR 风险：

一旦事件从个案变成群体经验的投射，品牌不能只用个案处理逻辑回应。

## 道德层

道德层回答：

- 公众最终在审判什么？
- 是事实错误、态度傲慢、权力滥用、性别不公、阶层炫耀、隐私侵犯、商业欺骗，还是私人道德？

PR 风险：

很多危机表面是事实争议，实质是公众对责任、权力和公平的审判。

# 2. 爆料格式判断表

| 格式 | 传播优势 | 主要风险 | 品牌响应方式 |
| --- | --- | --- | --- |
| 聊天截图 | 私密、真实、易截图转发 | 断章取义、语境丢失、无限反转 | 恢复语境，明确边界，避免陷入碎片互锤 |
| PDF 长文 | 完整、正式、有证据感 | 叙事选择被包装成事实全貌 | 按事实点逐条回应，拆分已证实和待核实内容 |
| PPT | 要点清晰、可截图、强议程设置 | 将复杂问题简单化，制造汇报式说服 | 拆解叙事框架，指出省略、混合和暗示 |
| 短视频切片 | 情绪强、速度快、易破圈 | 上下文缺失，二创失控 | 用短解释纠偏，再提供长版事实说明 |
| 录音音频 | 现场感强，难以快速反驳 | 剪辑边界不清，听感压过事实 | 确认证据完整性，避免直接否认可感知内容 |
| 检测报告 | 专业、可验证 | 普通用户看不懂，容易被再解读 | 用专家解释和 FAQ 转译关键结论 |
| 评论区高赞 | 提供经自我选择和平台排序后的可见意见线索 | 被误当成整体公众、发生率或事实共识 | 纳入研判，同时核验样本偏差、排序机制和外部证据 |

# 3. 舆情响应三层结构

## 第一层：事实框架

目标是降低信息混乱。

应该做：

- 列出已确认事实。
- 列出仍在核实的信息。
- 说明核实机制和时间点。
- 对错误信息逐条澄清。

不要做：

- 用一句「网传不实」覆盖所有争议。
- 用法务措辞替代公众解释。
- 为了快而发布无法承受追问的结论。

## 第二层：价值框架

目标是回应公众真正关心的道德问题。

应该做：

- 承认公众为什么会在意。
- 说明品牌对权力、责任、消费者、员工、弱势方或公共利益的态度。
- 让价值表达和行动对应。

不要做：

- 把公众的不满全部说成误解。
- 只谈流程，不谈伤害。
- 用「个别事件」回避结构性问题。

## 第三层：格式框架

目标是对抗误导性叙事结构，而不是只对抗单个事实点。

应该做：

- 针对不同传播格式设计不同回应格式。
- 对长文档用表格回应，对短视频用短解释回应，对复杂争议用长文、访谈或 FAQ 回应。
- 把回应做成公众能理解、媒体能引用、内部能执行的材料。

不要做：

- 用单一声明应对所有传播格式。
- 让品牌回应在传播效率上输给爆料材料。
- 忽视评论区、切片号、二创图的二次叙事。

# 4. 宠物食品行业迁移

当宠物食品争议涉及生命、安全、照护责任、信息不对称或企业可控性时，产品事实可能被转译为更大的道德问题；行业类别本身不能推出这一结果。

## 常见转译路径

- 食品安全：从「某批次问题」转向「品牌是否把宠物当生命」。
- 配方争议：从「技术参数」转向「品牌是否傲慢或欺骗」。
- 代言/KOL 争议：从「合作选择」转向「品牌价值观」。
- 价格争议：从「成本结构」转向「是否收割养宠焦虑」。
- 客诉处理：从「个案」转向「企业是否尊重消费者」。

## 内部研判表

| 维度 | 要回答的问题 |
| --- | --- |
| 事实 | 具体产品、批次、渠道、时间、证据是什么？ |
| 格式 | 舆情最初以什么形式出现？截图、测评、视频、长文、群聊？ |
| 情绪 | 用户愤怒来自损失、恐惧、被轻视，还是价值背叛？ |
| 身份 | 谁最容易被激活？猫狗主人、救助人、繁育人、医生、KOL 粉丝？ |
| 平台 | 主要发生在小红书、抖音、微博、微信群，还是电商评价？ |
| 回应 | 需要短回应、长解释、检测报告、第三方背书，还是售后动作？ |
| 风险 | 哪些话会扩大冲突？哪些证据不能公开？哪些承诺不能随便给？ |

# 5. 使用原则

1. 不要只问「发生了什么」，要问「它被做成了什么格式」。
2. 不要只看爆料者说了什么，要看公众为什么愿意相信。
3. 不要只回应事实点，要回应公众真正审判的道德问题。
4. 不要让回应格式弱于爆料格式。
5. 不要把高赞评论当噪音，也不要把它当整体公众；它只是经自我选择和平台排序后的可见意见线索。
6. 不要用大字报回应大字报；要把讨论拉回事实、程序、责任和改进。

---

# 6. 适用场景

- 截图、聊天记录或录音引发争议。
- 消费者投诉被做成长文或视频。
- KOL 或员工爆料形成跨平台扩散。
- 品牌被卷入性别、阶层、地域、动物伦理或公共价值争议。
- 品牌需要判断是否回应、如何回应、用什么格式回应。
- 内部复盘舆情时，需要区分事实问题、格式问题和价值问题。
