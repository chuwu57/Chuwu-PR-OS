# Framework: PR 叙事适配四变量

用于判断一个行业、品牌或新赛道能否直接套用已有传播方法。

核心判断：PR 方法论未必变化，真正变化的是四个适配变量。

## 策略

品牌现阶段选择什么取舍。

例如：追求进步叙事、效率叙事、科技叙事，还是公平叙事、信任叙事、责任叙事。

## 内容

品牌具体讲什么。

重点不是把事实说完整，而是判断哪些事实在当前语境下能建立信用，哪些事实会刺激新的疑问。

## 渠道

信息在哪里被分发、被解释、被扭曲。

同一内容在媒体、短视频、小红书、公众号、社群、内部会议里的理解方式不同。

## 读者

谁在读，带着什么情绪和预设读。

中国语境下，读者未必优先接受商业理性或进步主义解释，很多时候更在意公平、情绪和具体人的处境。
