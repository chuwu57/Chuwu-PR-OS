# Framework: SCCT危机回应匹配法

## 用途

用于危机中判断组织责任归因、公众情绪和回应强度之间是否匹配。

核心判断：危机回应不是选一句好听的话，而是让事实、责任、情绪、行动和承诺匹配。

理论边界：本框架是[危机责任、信源与修辞竞技场](../15-Theory/Communication/40_Crisis-and-Risk/Theory_Crisis-Responsibility-Sources-and-Rhetorical-Arenas.md)的执行转译。SCCT主要判断责任归因与声誉威胁，不能替代生命安全、监管义务和受影响者补救。涉及真实伤害时，先执行[Framework_PR-Decision-Gate](Framework_PR-Decision-Gate.md)的Reality与Harm门，再讨论声誉回应策略。

危机回应的关键风险不是「文案不够漂亮」，而是回应与事实、伤害和责任错位。低责任场景里过度道歉可能增加责任联想；高责任场景里只做事实说明可能被部分公众理解为冷漠和推诿；事实尚未查清时急于定责也可能制造二次风险。SCCT匹配法的价值，是先判断公众如何归因，再决定回应姿态，而不是从模板声明里挑一句；它是诊断起点，不是结果保证。

## 1. 四步判断

| 步骤 | 要问的问题 |
|---|---|
| 危机类型 | 是谣言、事故、过失、违规、价值观争议，还是系统性问题？ |
| 责任归因 | 公众认为组织责任低、中、高，还是已默认有罪？ |
| 强化因素 | 是否有危机历史、坏声誉、受害者叙事或平台放大？ |
| 回应策略 | 应告知、关怀、解释、道歉、补偿、整改，还是组合使用？ |

## 2. 责任归因不是法律责任

PR里的责任归因有三层：

| 层级 | 说明 | 对回应的影响 |
|---|---|---|
| 法律责任 | 法规、合同、司法或监管意义上的责任 | 决定能否承认具体过错和补偿边界 |
| 运营责任 | 流程、管理、体验、售后、信息披露是否有问题 | 决定是否需要整改、复盘和负责人机制 |
| 情感责任 | 公众认为品牌是否尊重人、是否把影响当回事 | 决定是否必须先关怀、道歉或解释姿态 |

很多危机里，法律责任尚未确认，但情感责任已经很高。此时不能用「暂无定论」替代关怀，也不能用「依法处理」替代解释。

## 3. 回应匹配表

| 公众责任归因 | 可用回应 | 禁忌 |
|---|---|---|
| 低 | 事实告知、风险提示、持续更新 | 过度道歉可能增加责任联想 |
| 中 | 解释原因、表达关怀、说明处置 | 只讲流程不讲影响 |
| 高 | 道歉、补偿、纠偏、负责人机制 | 否认、甩锅、拖延 |
| 已被价值审判 | 行动优先，价值回应跟上 | 空泛表态、法律威胁 |

## 4. 强化因素检查

即使事件本身责任不高，以下因素也可能改变责任归因、伤害判断、信息需求或信任，需要分别核验：

1. 有相似危机历史，公众认为「又来了」。
2. 行业本身信任低，品牌背负行业刻板印象。
3. 受害者叙事清晰，用户损失具象且容易共情。
4. 品牌前后口径不一致，造成隐瞒或改口印象。
5. 当前平台分发是否让冲突性短视频、截图或聊天记录获得更高可见性。
6. 涉及弱势群体、儿童、宠物、健康、安全、民族情绪或公平议题。

这些因素不能简单累加成回应强度。只有在核验它们实际改变了责任归因、现实伤害、信息需求或信任后，才决定是否增加关怀、时间表、第三方验证和持续更新。

## 5. 回应组合

不要把回应策略理解成单选题。常见组合是：

| 场景 | 组合 |
|---|---|
| 谣言或误读 | 事实告知+证据源+持续监测 |
| 体验损害 | 关怀+解释+补救方案 |
| 运营过失 | 道歉+补偿+流程整改 |
| 安全风险 | 风险提示+召回/下架+第三方检测+进度更新 |
| 价值观争议 | 承认伤害+解释背景+行动修正+长期机制 |
| 恶意攻击 | 事实源+证据链+必要法律动作，但避免把普通质疑者一并打成攻击者 |

## 6. 内部使用原则

1. 先关怀，后争辩。
2. 先止损，后追责。
3. 先公开可确认事实，后承诺时间表。
4. 高责任归因场景中，行动比措辞更重要。
5. 不要用法务语言替代公众语言。

## 7. 输出标准

一次合格的SCCT匹配判断，应明确输出：

1. 当前危机类型。
2. 公众责任归因等级。
3. 放大归因的强化因素。
4. 建议回应组合。
5. 第一轮回应必须说什么，不能说什么。
6. 后续用什么行动降低责任归因，而不是只降低声量。

## 8. 消费品PR迁移

当消费品危机中的伤害贴近身体、安全、家庭，或公众有证据认为企业具有较高控制性责任时，责任归因可能更高；食品、美妆、母婴、宠物、家电、健康产品的行业类别本身不能推出归因结果。即使事实责任未完全确定，也应先处理现实安全和受影响者处境，再进入责任边界说明。
