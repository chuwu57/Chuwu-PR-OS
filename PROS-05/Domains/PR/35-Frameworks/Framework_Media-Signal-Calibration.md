# Framework: 媒体信号校准

## 解决什么问题

用于读取媒体报道、机构号、企业供稿、行业内容和个人创作者材料时，判断这个来源更容易看见什么、忽略什么，以及文章经过多少独立编辑加工。

核心判断：媒体不是事实本身，而是带有角色、准入条件、专业能力和利益结构的传感器。传感器偏向用于校准证据，不用于预判文章真假。

## 五问校准

| 问题 | 判断内容 |
|---|---|
| 谁在感知 | 央媒、技术媒体、商业媒体、产业媒体、机构号、个人创作者或平台用户 |
| 它靠什么接近事实 | 政策与机构准入、企业高管、论文与开发者、客户现场、供应链、个人实测或公开讨论 |
| 核心事实由谁提供 | 监管与正式文件、企业、客户、员工、专家、媒体现场、外部测试或作者个人体验 |
| 编辑加工到哪一层 | 承载转载、技术注释、编辑采访或多方调查 |
| 它能证明什么 | 企业主张、技术位置、组织意图、现场状态、公众体验或经交叉验证的事实；同时写明不能证明什么 |

## 常见传感器偏向

| 来源角色 | 更容易捕捉 | 常见盲区 |
|---|---|---|
| 央媒与官方科技媒体 | 政策、科研、国家工程、代表性产业进展 | 失败率、采购成本、长期商业结果 |
| 技术媒体 | 论文、架构、Benchmark、开发者反应 | 客户留存、单位经济性、组织约束 |
| 商业媒体 | 组织、资本、预算、竞争与高管决策 | 技术复现、匿名信源的外部可检查性 |
| 产业媒体 | 供应链、展会、工厂、交付和客户现场 | 自有会议、合作伙伴与企业准入带来的选择偏差 |
| 个人创作者 | 真实使用摩擦、快速测试、用户语言 | 样本代表性、环境差异与可重复性 |
| 机构号与企业供稿 | 企业路线、产品口径、计划和案例 | 独立评价、反方材料与失败条件 |

这些偏向是研究先验，不是文章定性。央媒可以做调查，个人创作者也可以严谨复现；最终仍以具体信源和加工过程为准。

## 编辑加工四级

| 层级 | 可观察特征 | 最强可支持结论 |
|---|---|---|
| L1承载／转载 | 结构和措辞主要来自企业稿，仅改标题、导语或排版 | 企业公开说了什么、希望建立什么认知 |
| L2技术注释 | 增补论文、参数、同类产品、公开数据或开发者评论 | 产品或技术在公开路线中的位置 |
| L3编辑采访 | 有记者提问、现场细节、署名编辑和对关键选择的追问 | 企业为何这样决策、现场呈现了什么 |
| L4多方调查 | 公司、客户、员工、竞争者、专家或独立数据相互核对 | 在样本和信源边界内形成较强独立判断 |

层级表示独立加工强度，不是质量总分。L4仍可能受匿名信源、样本和框架限制；L1也可能准确承载重要的一手声明。

## 商业关系边界

- 广告、机构号、会议、品牌服务和商务合作入口只能证明商业结构存在。
- 没有明确标签、合同、双方披露或其他公开证据时，不判断具体文章属于付费合作。
- 没有付费证据也不等于没有企业影响；独家准入、提前体验、数据供给和高管关系都可能塑造选题。
- 输出应优先描述「企业信源主导」「新闻稿依赖」「编辑加工有限」或「多方核验」，少猜动机。

## 输出最小结构

一次媒体信号校准至少写清：

1. 来源角色与接近事实的路径；
2. 核心事实由谁提供；
3. 编辑加工层级及具体依据；
4. 当前材料能证明和不能证明什么；
5. 需要哪类不同传感器补足盲区。

## 使用边界

- 不根据媒体类型给可信度总分。
- 不把标题风格直接等同于商业合作。
- 不为每个媒体建立长期画像或内容总库；只有真实任务需要时才按需更新。
- 单篇文章分析使用`media-narrative-analysis`；公共事件整体走势使用`hot-public-opinion-analysis`；跨案例或同一事件多版本研究通过`follow-loop`的传播案例lane按研究问题读取必要证据。
