# Framework: 外源型数据危机处置框架

用于勒索攻击、第三方系统漏洞、用户信息泄露、黑客声称窃取数据等事件。

## 判断起点

外源型危机看似责任归因较低，但如果企业披露不充分、淡化事实或被第三方证据打脸，会从「受害型危机」滑向「诚信受损型危机」。

## 四条原则

1. 抢第一叙事者位置：尽量早于攻击者或与攻击者同步披露已知事实。
2. 一次说清已知坏消息：避免「挤牙膏」式更新制造二次信任坍塌。
3. 给受影响者掌控感：提供查询通道、自我保护工具、补救安排和更新节奏。
4. 区分能力与诚信：能力不足可以整改，事实误导会摧毁信任。

## 协同要求

数据危机不是安全部门单点问题，必须建立公关、安全、法务、客服和管理层的联动机制。安全社区、黑客论坛和垂直媒体也应进入舆情前哨。
