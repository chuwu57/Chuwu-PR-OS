# Framework: AI 产品传播四账户模型

用于判断 AI 产品、模型发布、开源动作、人才流动和创业公司竞争传播是否完整。

## 四个账户

### 用户使用账户

面向普通用户，回答「我为什么现在要用」。

观察重点：

- 功能是否被翻译成生活动作。
- 场景是否具体到可拍、可截、可分享。
- 内容是否有娱乐性、陪伴感、身份感或实际效率。
- 用户是否能用自己的话复述产品价值。

### 开发者信任账户

面向开发者和专业用户，回答「我为什么愿意试、接入、推荐」。

观察重点：

- Benchmark 是否可解释。
- 技术报告是否清楚边界。
- API 价格、稳定性、上下文和工具链是否可用。
- 开源路径、协议和社区反馈是否可信。
- 团队是否愿意承认不足并回应问题。

### AI心智／主体性主张闸门

当传播使用「理解」「思考」「同理心」「自主决定」「超人」等词时，必须拆开四层：

- 可测任务能力：系统在哪些任务、条件和指标上表现更好。
- 用户体验：用户是否感到被回应、被帮助或更高效。
- 心智主张：是否有独立证据支持理解、感受、意图或道德判断。
- 责任主体：谁设定目标、部署系统、获得利益并承担错误后果。

流畅输出不能单独证明理解，合适安慰不能单独证明共同关系，「AI决定」不能代替组织问责。若只能证明前两层，对外措辞就停在能力与体验，不升级成心智或主体性承诺；`superhuman`必须限定具体任务和比较条件。

### 人才资本账户

面向人才市场、资本市场和行业观察者，回答「这家公司有没有长期能力」。

观察重点：

- 顶尖人才加入是否对应明确战略问题。
- 汇报线、scope、团队位置是否说明组织重视程度。
- 融资、商业化、收入结构和成本叙事是否能支撑长期路线。
- 公司是否避免把人才传播做成单纯薪资八卦或天才消费。

### 生态节奏账户

面向行业生态，回答「这家公司在牌桌上的位置如何变化」。

观察重点：

- 是否抓住模型、开源、价格、榜单、社区、竞品和平台热点。
- 发布节奏是否连续，而不是单次爆发。
- 是否选择了可赢战场，而不是和大厂全面硬拼。
- 生态伙伴、开发者社区、媒体和用户是否共同放大同一方向。

## 核心判断

AI 产品 PR 的难点不是缺少话题，而是不同人群需要不同证据。

大众用户需要场景和动作，开发者需要可验证能力，人才和资本需要组织信号，行业生态需要持续节奏。

四个账户同时变厚，AI 传播才不只是一次发布，而会变成公司长期被理解、被试用、被信任的系统。
