# Framework: 价值观前置审查框架

用于广告、营销、联名、节日传播、达人合作、出海内容投放前的风险检查。

## 五组检查

1. 身份与群体：是否物化、标签化或对立化某类人；是否默认女性承担纯洁、亲和、照护、体谅等额外给予义务，女性表达权威、拒绝或索取时是否换用更严标准。
2. 文化与符号：是否误用历史、民族、宗教、地域或他文化符号。
3. 价值观与导向：是否传递落后、冒犯或容易被误读的婚恋观、消费观、成功观。
4. 第三方与外包：外部内容是否按自有内容同等终审，品牌是否承担最终责任。
5. 应急预案：是否预设数小时内的响应机制、表态口径和纠偏动作。

## 性别化双重标准的证据边界

审查先比较同类角色：相同行为由不同性别作出时，是否被解释成领导力／野心、坚定／刻薄、边界／自私；是否只有女性需要额外证明温暖、无私和完美受害者。若存在「给予期待→拒绝或索取→惩罚」链，父权规范执法解释增强。

单条冒犯文案可以支持「出现性别化框架或双重标准」的判断，不能单独证明完整的厌女执法系统。升级到制度性结论还需角色规范、权力差、重复奖惩、同类男性比较和组织支持证据。对外表达优先写清具体标准和伤害，避免用标签替代证据。

## 组织原则

价值观红线的最终解释权不应完全交给追求流量和转化的角色，应让熟悉在地语境且不被短期数据绑定的人拥有实质否决权。
