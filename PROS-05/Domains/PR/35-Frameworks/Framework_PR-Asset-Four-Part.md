# Framework: 公关资产四分法

公关资产是品牌长期公共活动积累而来的声誉资本和关系网络。

## 舆论资产

品牌在公众心中的舆论土壤。

作用：

- 承接品牌变动。
- 对冲部分危机。
- 影响新品、价格、争议和延展业务的接受度。

## 媒体关系资产

与媒体、行业观察者、内容生产者之间的信任关系。

作用：

- 降低沟通成本。
- 提供外部视角。
- 在关键时刻增加解释和协调空间。

## 话语体系资产

品牌能否用稳定、可信、可复用的语言解释自己。

作用：

- 建立长期叙事连续性。
- 降低每次传播重新解释的成本。
- 让外部更容易理解品牌的合理性。

## 内部能力资产

组织内部对风险、传播、用户和公共关系的理解能力。

作用：

- 提升跨部门响应效率。
- 减少公关被动救火。
- 让公关意识渗透到业务流程。


## 从项目积累到下一次调用

组织架构图只能说明汇报关系，不能独立证明执行能力。需要判断团队能否承担某项传播或应对任务时，核对相关人员的业务背景、能力配比、发言与替补安排、协作方式及已有交付；资料不足时保留能力缺口，不因岗位齐全就认定能够完成任务。此项依据初五成稿中的组织判断，服从本次任务范围，不把单次文案工作扩展为全面组织审计。

初五与于一凡的对话中，初五04:51再次区分个人判断能力与组织积累，并列出公众认知、持续接触的关系、解释材料和应对机制。它补充现有四分法的调用视角，不另建一套同义资产分类。17:08的合作报道复用自述、18:38的材料补缺循环、01:53:12—01:54:12的活动素材观，为以下方法提供经验来源。

「资产化公关」是后续AI对这组判断的概念归纳，非本人当场命名，当前也不作为独立、已验证的理论。它强调：一次传播既要完成当期目的，也应判断哪些积累值得在后续任务中继续使用。

可用下列路径组织复盘：

> 生意问题→传播目的→传播动作→素材、关系与知识的沉淀→下一次调用与反馈。

素材、关系与知识可以并行形成，不能机械设成串行交付阶段。04:51、10:38—14:32提示，维护深度取决于未来用途；没有调用需求的详尽整理可能只增加成本。对值得保留的资产说明谁会在什么任务中使用、依赖哪些事实与权限、何时需要更新；简单事项保留最少信息即可。

|既有资产|下一次使用时需要能够回答|
|---|---|
|舆论资产|相关人群实际怎样理解品牌，仍有哪些疑问；不能用曝光量代替认知证据。|
|媒体关系资产|对方愿意在哪些议题上再次交流，企业能提供什么；通讯录与单次到场不能证明关系可调用。|
|话语体系资产|产品事实、解释依据与使用场景是否清楚，材料是否仍有效，哪些内容可公开。|
|内部能力资产|谁能发言、谁可代为发言、谁负责准备；对外接触者能否准确解释关键事实及边界。|

复用是否有效，需要看下一次是否减少重复解释、改善判断或缩短协作，不能由文件数量推定。关系会中断，材料会过期，个人经验也不自动成为组织能力。「任何事情都是一个素材」表示留意业务活动的内容潜力，仍需按相关性、事实、授权和维护价值选择，不等于所有事情都应公开、存档或转成Skill。
