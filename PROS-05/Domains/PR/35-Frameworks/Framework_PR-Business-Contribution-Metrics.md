# Framework: PR 商业贡献指标框架

用于替代 PR Value、公关价值折算、总曝光量等低质量指标。

## 投入前对齐职责、目的与结果

在确定岗位或项目投入时，先与业务及决策人讲清公关负责哪些动作、这些动作试图改变谁的理解或关系、哪些结果可观察，以及哪些决定仍需业务或管理层作出。职责与结果的理解一致，才能使事后评价有共同依据。

初五访谈10:49—13:39强调这一事前对齐：消费者信任、渠道愿意了解、媒体准确解释都可能帮助经营，但销售由多环节共同决定；未发生危机，也不足以单独证明节省了确定金额。管理层仍需拍板本身不说明公关无价值，要看是否提前明确了信息组织、建议与决策的分工。

25:31—27:26中没有固定预算、ROI或KPI的描述属于特定组织经验；其仍观察传播、搜索、负面主题和VOC变化。不能由此推出公关无需评估，也不能将所有关系价值强行折算为单一销售指标。上述事前安排是经验启发，效果仍需实际协作检验。

## 三类指标

### 心智占位

- 品牌词、品类词、问题词的搜索占位。
- 核心媒体和社区中品牌被解释的方式。
- 从参数认知到价值认知的变化。

### 信任转向

- 核心社区中质疑、观望、推荐的比例变化。
- 媒体和 KOL 是否愿意在争议中给品牌解释空间。
- 负面问题出现时用户是否先等待官方解释。

### 商业辅助

- PR 内容触达后的官网访问、注册、询盘、渠道搜索。
- 媒体内容在销售、客服、BD、融资中的复用情况。
- 危机预警或澄清减少的潜在损失。

## 代理值边界

使用指标本身不构成value capture。风险出现于：外部环境提供简化的价值表达，团队没有依据真实业务和关系经验充分调整，随后让该表达支配实践推理。互动率、声量和报道数可以提供信息；当团队把它们直接当成信任、理解或商业贡献，并停止接受反证，代理值才开始接管原价值。

每个核心指标必须同时记录：它代理什么、遗漏什么、什么真实经验会要求修改解释、何时即使数字上升也应停止行动。大尺度统一指标有时有协调价值，仍需保留本地判断与多尺度价值；增加更多指标不能自动解决捕获。

## 舆情复盘中的三层对齐

量化前与业务、渠道对齐口径、时间窗和可比较基线。按天或关键处置节点记录发帖、互动、负面主题及传播路径；总量下降还要结合语义抽样，区分问题得到解决、关注自然衰减和讨论转移。

再把传播变化与渠道搜索、转化、停售／关播等实际影响放在同一时间轴。声量严重与即时销量损失是不同判断；渠道暂未受影响，也不能推出伤害不存在或长期信任没有成本。团队的体感可以提示语义遗漏，需要回到可复核的内容样本。

最后区分相关与归因：季节、促销、供货、平台分发等变量会同时影响业务曲线。没有对照和充分识别时，只报告同步变化及合理解释，不宣称处置挽回了确定金额。这是对初五个人实践方法的有边界吸收，尚不构成一套已验证的因果测量模型。

## AI效率与结果价值分开评估

AI缩短交付工时后，仍需分别记录生产效率和组织结果。方案更快、稿件更多、成本更低属于生产端；目标公众是否理解、使用服务、选择产品或愿意再次合作属于结果端。先明确希望谁发生什么变化、可比较基线和观察期限，再配置交付与费用，避免将省下的工时直接称为创造的品牌价值。

Waddington的讨论支持这一方法取舍，尚无跨组织效果验证。绩效收费只宜覆盖口径可核验、责任可归属的结果部分；季节、促销、产品与渠道等共同作用必须保留。内部仍需记录工时和成本，不能因追求价值定价就失去资源管理。

## AI品牌回答的三个不同指标

固定购买问题、模型与版本、地区语言和测试时间，保留原始回答并在每个条件下重复测试，分别观察：

- 提及：品牌是否进入回答，以及事实是否准确。
- 推荐：是否被优先选择，推荐依据与不适用条件是什么。
- 稳定性：相同条件下重复回答的一致程度，以及跨时间的变化。

三者分别报告，不能把被提及当作被选择，也不能用一次首选回答代表稳定位置。测量设计来自LEOPRD公开方法的启发；其英澳样本、商业利益和未复跑的原始数据限制外推。收入风险估计须标明模型假设，不能当实际损失；中国品牌须另建本地基线，并与真实用户选择相互校验。

## 核心原则

PR 的价值不是把曝光折算成广告费，而是让品牌更容易被理解、被相信、被选择，并在危机中少付信任成本。
