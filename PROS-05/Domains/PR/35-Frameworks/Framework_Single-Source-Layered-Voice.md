# Framework: 单一事实源与分层语态框架

用于社区先爆负面、客服 Bug 高压、跨部门危机和全球多渠道回应。

## 单一事实源

所有对外表达必须共享同一份底层事实：

- 已确认事实。
- 尚不确定事实。
- 当前行动。
- 对用户的直接影响。
- 补救入口。
- 下一次更新时间。
- 禁止表达和敏感边界。

## 指称地图

单一事实源还需固定同一事实由哪些对象构成：

- 责任主体与直接行为者。
- 事件、产品／批次或规则版本。
- 发生时间、统计区间与当前更新时间。
- 受影响对象、地域和数量范围。
- 已确认、争议中、假设、否定和待核验状态。

同一名称、简称、代词和「该事件」「有关方面」「个别情况」都要指向唯一对象。内部团队知道在说什么，不能替代文本为外部受众建立先行项。

## 分层语态

- 官网 / 新闻稿：准确、克制、承担责任。
- 社媒：清楚、短句、可转发。
- 社区：人话、解释感、互动感。
- 客服：具体步骤、补偿路径、情绪承接。
- 高管：价值立场、责任承诺、组织改进。

## 核心原则

口径一致不是所有渠道说同一句话，而是底层事实一致、表达方式适配场域。

分层语态可以改变长度、语气、信息顺序和解释密度，不能改变命题、指称对象、责任边界、时间／因果关系和事实状态。任何渠道删减后若让「谁做了什么、影响哪一范围、目前确认到哪里」出现多个合理答案，就已越过语态适配，变成语义漂移。

## 语境闭合

渠道切换、单条转发、截图、媒体引述和跨段阅读都会切断原先行项。每个可独立流通的版本都要重新检查：

1.首次出现的主体、事件、时间和范围是否完整明示。
2.代词、示指词、省略主语和简称是否只有一个公开可恢复的先行项。
3.被讨论、被否定、被假设和已确认是否清楚区分；被突出不等于被接受或被证实。
4.脱离上一段或上一渠道后，读者能否复述「谁、什么事、哪一范围、目前状态、下一步」。

答案分叉时，重新写出完整对象与事实状态。这里借用的是微观话语中的指称可恢复性检查，不把语言学prominence等同媒体显著性、议程设置或说服效果。
