# Framework: 用户动员与舆情升级链路框架

用于危机预判时模拟用户、粉丝、消费者、路人如何把不满转化为公共压力。

## 六级链路

1. 私域/封闭反馈：客服、邮箱、VIP 客服、电话客服等一对一渠道。
2. 半公开喊话：官号评论区、官方论坛、品牌社群等官方可见场景。
3. 组织化协同：统一物料、统一话术、统一节奏、联名文书。
4. 素材生产：事件事实、测试证据、权益话术、价值升级、旧账挖掘、公司问题化、回应二创。
5. 行动施压：抵制、退款、停氪、冲直播、集中开发票、应用商店差评。
6. 制度/第三方放大：投诉平台、监管举报、律师函/诉讼、媒体跟进、热搜和词条。

## 判断变量

- 用户投入强度：时间、金钱、身份认同和沉没成本越高，持续行动概率越高。
- 可见性：封闭沟通是否会外溢为截图、录音、表格、短视频或投诉数据。
- 素材化能力：事件是否能被简单、可转发、可证据化地表达。
- 合法性叙事：争议是否能上升为权益、公平、安全、文化、性别、民族情绪等公共议题。
- 外部节点：媒体、平台、投诉渠道、监管、合作方和法律路径是否容易介入。
- 技术门槛：AI 会降低渠道匹配、话术整理、材料生成和行动协同成本。

## 核心判断

公关不需要预设用户恶意，但必须预判用户可用动作。

「有组织」应先被看作传播效率变量，而不是道德判断。过早把用户行动定性为恶意或水军，会让组织错过理解诉求、降低烈度和修复关系的窗口。
