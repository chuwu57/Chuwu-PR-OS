# Strategy: Disputed Facts and Evidence Communication

## 适用问题

事件由检测报告、事故数据、竞品举报、专业判断、网民分析、录音视频或单方指控触发，现有材料看起来具体，却可能无法直接支持传播中的终局结论。组织需要决定如何核验、是否澄清、能否反击，以及如何在专业事实未定时保护信任。

## 核心取舍

证据沟通不是「拿出一份对我有利的报告」，而是让外界看清主张、对象、方法、范围、来源、证据总体、选择过程和裁决路径。单项材料完全真实，也可能因选择性生产、发表或重复呈现而误导。组织可以强硬纠正明确不实信息，但不能把内部自证、局部样本或不同方法的结果包装成终局。

专业争议中，扩大保护动作与缩小结论范围可以同时进行。

## 八格证据表

每个核心争议都填写：

| 字段 | 判断问题 |
| --- | --- |
| 主张 | 谁明确声称了什么 |
| 对象 | 针对哪个产品、批次、时间、人员或行为 |
| 方法 | 如何取样、检测、计算、剪辑或推断 |
| 范围 | 结论能覆盖到哪里，不能覆盖哪里 |
| 来源 | 当事方、企业自查、第三方、监管还是司法 |
| 状态 | 已确认、可复核、存在冲突、调查中或已裁决 |
| 总体 | 该结果在完整证据分布中的位置，是否同时存在阴性、相反或未公开结果 |
| 选择 | 谁决定研究什么、发表什么、摘要什么和反复呈现什么；材料是否独立，是否只是同一来源的转述 |

对象、方法、范围、来源或状态不清，或关键结论无法说明它在证据总体和选择过程中的位置时，不发布绝对结论。八格不是要求每次填满形式，而是防止用一项真实材料冒充完整证据。

## 证据等级

1.未经核验的公开主张：只能说明「有人提出」。
2.原始材料可检查：文件、视频、数据或样本存在，但解释仍可能争议。
3.企业内部核验：可支持组织行动，独立性有限。
4.独立专业核验：方法和对象清楚，可支持对应范围。
5.监管或司法结论：在其法定事项和范围内具有更高裁决力。

高等级不自动覆盖不同对象和不同问题。例如某批次抽检合格，不能证明所有批次；未发现违法，不能自动证明消费者体验不存在。

## 外部核验的独立性如何判断

独立性需要核对实际安排：谁选择和支付评估者、谁决定范围、能接触哪些原始材料及人员、能否发表不利发现和访问受限情况、删改及分歧如何处理。持续运行的AI系统还需说明一次性评估与持续访问的区别。未披露的安排保留未知，不能用机构名称直接填补。

Dario Amodei的公开方案为访问权与发表权提供了具体设计参照，目前仍属承诺。将它用于消费者争议时，应按问题调整为样本、原始记录、方法和现场访问等必要条件；不机械要求所有评估者取得员工权限。核验安排已公布、实际执行、独立报告与整改有效是不同状态，公开表达须分别验收。

### 把未评内容与删节影响交代清楚

委托外部评估时，事先说明要回答的主张、对象、方法与范围；公开结论时同步列出未评事项、访问限制和仍不确定的问题。若材料有实质删节，应交代删节类别及其对结论可检查性的影响，在必要保护与公众理解之间提供足够解释。

OpenAI的第三方评估原则补充了这一设计参照，仍属于组织承诺。可迁移的是评估边界与发表条件，不能把其原则名称当作消费品检测标准，也不能把一次第三方评估写成对产品全部表现或发布决定的认可。

## 检测、实测与反转主张：先确认是否同题

先把材料还原成能够分别检验的主张：发生过什么、某组样本在什么条件下表现如何、什么要求已被验证、原因是否已解释、适用范围有多大。两份材料描述不同对象或条件时，结果可以并存；新报告出现不自动推翻旧观察，旧观察也不能自动推翻所有标准检验。确认是同一命题后，才讨论证据是否足以更正原结论。

对照只保留会改变判断的条件：样品来源与版本／批次、部件或整机、实际测试配置、施加条件与时间过程、重复次数、失效判据、测量和记录完整性。技术参数由原报告与专业主体核验，PR不凭视频或媒体解释诊断根因。仅有摘要时明确未取得的原始记录；无法取得不等于对方没有。

多档测试须让每组样本数、条件和结果一一对应。最高测试值不代表所有样本都经历该条件，样本结果不自动覆盖全部量产或所有使用情境；更大的单项参数也不能在其他条件未对齐时证明整体覆盖。合规主张须注明对应项目与版本，不由一项合格推出一切风险已排除。

机构确认出具报告、流传版本是否完整、报告能覆盖什么对象，是不同问题。「仅对送检对象负责」不能被改写为报告无价值；「无法保证外传版本未被改动」也不能被改写为已经发现造假。反过来，机构身份和报告真实性不能填补方法与代表性缺口。

## 事实、补救与公众反应分别更新

事实争议已解决，需要能回答争议本身的证据；补救已兑现，需要相应范围内措施到达受影响者并完成核验；公众反应发生变化，需要有时间与对象边界的反馈或传播证据。宣布调查、承诺升级、开始服务和完成处理分别保留状态，不从一次声明、报告发布或热度变化推定整体结案。

这些状态允许不同步：部分错误说法被澄清后仍可能需要处理真实伤害；有保护动作也不等于已经认定全部责任。原因未明时按既有行动优先原则识别保护与补证需要，不等待结案才行动。舆情分析说明暴露和触发条件；最终业务取舍沿现有Workflow处理。无需给普通告知额外制作三套台账。

## 四类回应

### 1.事实澄清

适用：存在明确可证伪信息，组织拥有原始材料。

动作：给出简短结论、原始入口、时间线和可复核方式。避免追着每个账号争辩。

### 2.方法校准

适用：双方使用不同样本、标准或检测方法。

动作：对齐对象和方法，说明结果为什么不可直接比较，推动共同或独立复核。

### 3.调查等待

适用：重大责任依赖监管、司法、医学或技术调查。

动作：说明已提交哪些材料、临时保护动作和更新时间，不抢占终局。

### 4.责任回应

适用：关键事实已经确认，争议只剩责任和补救。

动作：停止继续举证对抗，进入道歉、补偿、整改和复核。

## 公开材料设计

- 用时间线替代情绪声明。
- 用主张—证据对照表替代选择性截图。
- 提供原始文件或稳定入口，同时保护隐私和安全。
- 图表必须说明样本、口径和来源。
- 争议依赖多项研究或检测时，展示总体分布、阴性与冲突结果，不只展示有利样本。
- 合并媒体报道、专家转述和研究摘要前先去重；共同引用同一底稿不算多份独立证据。
- 企业自查、受托检测和独立第三方必须明确标注。
- 更正错误时保留变更说明，不静默修改。

## 是否反击

同时满足以下条件才进入公开反击：

- 对方核心说法可以被可靠证据直接证伪。
- 不存在尚未处理的用户伤害。
- 反击不会妨碍监管、司法或专业调查。
- 组织可以公开完整证据，而不是只发有利片段。
- 反击对象和力度符合比例，不把普通质疑者当作敌人。

不满足时，优先澄清事实、保护用户和等待独立裁决。

## 失败模式

- 把企业声明当作第三方结论。
- 用一份检测结果覆盖不同样本、时间和方法。
- 只展示对己方有利的真实结果，隐藏完整分布、停止规则或未发表结果。
- 把同一研究经多家媒体、多个账号和多次摘要后的重复传播当作独立交叉验证。
- 只回答技术真假，不回答消费者为什么担心。
- 在监管结论前公开给竞品、用户或员工定性。
- 以诉讼威胁代替证据，让事实争议升级为权力争议。

## 边界

本策略不判断医学、食品、工程、财务和法律结论本身。PR负责整理主张和证据边界、选择披露形式并防止越级外推；专业结论必须由相应主体作出。
