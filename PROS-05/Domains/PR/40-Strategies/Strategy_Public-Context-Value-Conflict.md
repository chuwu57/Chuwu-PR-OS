# Strategy: Public Context and Value Conflict

## 适用问题

广告、内容、高管表达、服务行为或全球政策触发性别、劳动、国别、地域、文化、阶层、环境或身份尊严争议。品牌需要决定是否停止内容、如何回应被冒犯群体、是否解释初衷，以及内部审核和本地化机制如何改变。

## 核心取舍

价值冲突首先是关系问题，不是创意说明题。品牌内部意图不能覆盖公众实际看到的权力关系和伤害。回应优先处理「谁被置于什么位置、品牌凭什么这样表达、现实动作造成了什么」，而不是证明创意团队没有恶意。

## 六步策略

### 1.停止继续放大

确认争议内容是否仍在投放、门店、直播、活动、达人账号和合作方渠道传播。停止不等于承认所有指控，而是避免在复核期间继续制造同类伤害。

### 2.识别被影响的身份和权力关系

判断：

- 谁被嘲弄、羞辱、教育、排除或代表。
- 品牌、高管、主播、员工与该群体之间是否存在权力不对称。
- 内容是否借弱势处境制造笑点、转化或优越感。
- 本地用户是否被当作次等市场或文化素材。

不要只统计支持与反对人数；低声量群体也可能承受真实伤害。

### 3.区分三种问题

| 问题 | 需要回答 | 主要动作 |
| --- | --- | --- |
| 事实错误 | 文化、历史、身份或产品信息是否错误 | 更正、下架、补专业审核 |
| 关系冒犯 | 表达把谁置于低位 | 道歉、停止、直接听取受影响者意见 |
| 组织价值冲突 | 行为是否反映长期制度或市场态度 | 管理层负责、改变审核和经营机制 |

三种问题可以同时存在，不能用纠正一个名词替代关系和制度修复。

### 4.回应伤害，不辩论敏感度

有效回应包括：

- 明确指出哪一表达或动作不当。
- 承认它造成的具体理解和伤害。
- 说明停止、撤回和纠正动作。
- 说明谁负责复核，机制将如何改变。

避免使用「部分网友误解」「原意是反讽」「大家太敏感」「没有任何恶意」作为主轴。

#### [本库迁移]历史责任型争议的修复核验

当争议涉及企业从奴隶制、殖民主义、种族化制度或长期环境不义中获益的主张时，先区分对方要求的是物质伤害修复、受损关系修复，还是产生伤害的制度重建。Táíwò把`harm-repair view`与`relationship-repair view`作为constructive view的竞争解释，并未提供「三者互补」的传播清单；PR场景把多类诉求分层处理，是本库迁移。

企业回应前做五项核验：

1.历史获益／伤害链是否有档案、合同、资产、供应链或制度证据。
2.该历史今天仍造成什么可观察的物质、关系或制度后果。
3.资源给谁、由谁决定，受影响者是否拥有否决、申诉和复核权。
4.方案是否改变主营业务、规则与权力，还是只用捐赠和纪念换取道德声誉。
5.哪些结果可由独立方验证，若核心历史主张不成立，是否会及时降级或撤回赔偿性表述。

无法证明历史谱系与差异负担时，不把一般公益、减排或社区投资自动命名为「赔偿」。能证明时，也不能用宏大历史替代对当次事实错误、关系冒犯和法律责任的分别处理。

### 5.修复本地判断机制

跨市场和文化项目至少建立：

- 本地决策者拥有否决权，而不是只负责翻译。
- 专业顾问对文化、历史、环境和身份议题进行事实审核。
- 一线团队可以上报全球政策与本地法律、用户预期的冲突。
- 活动和内容经过截图、去语境和受影响群体测试。

本地化不是换语言和符号，而是让本地利益相关方进入决策。

### 6.谨慎决定价值表态

只有当品牌存在长期行动、资源投入和一致记录时，才把危机回应上升为价值承诺。一次道歉不能自动证明组织价值已经改变。

## 是否由高管回应

需要高管出面：争议来自高管本人、全球政策、组织性差别对待或需要重大资源纠偏。

不宜高管出面：事实仍不清、高管只会重复道歉、其个人表达会制造新的权力感，或一线补救尚未完成。

## 失败模式

- 删除内容但不说明问题，留下「迫于舆论」的印象。
- 长篇解释创意初衷，逼受影响者接受品牌定义。
- 把文化审核交给翻译、代理商或活动执行的最后一环。
- 用公益捐赠替代对具体错误的承认。
- 全球总部和本地团队互相甩锅。

## 边界

公共争议不等于所有批评都成立。品牌可以纠正错误信息和拒绝恶意攻击，但应分别处理事实、关系和价值层；反驳不实指控时，也不能否认真实存在的公众感受和本地语境。
