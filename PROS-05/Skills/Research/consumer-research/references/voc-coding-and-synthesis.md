# 从消费者原话到可验证判断

处理访谈、评论、客服记录、开放题或流失反馈，需要从多条材料提炼购买、使用与放弃机制时读取。研究范围与主张强度继续服从[主张与证据匹配](claim-evidence.md)。单条反馈可以形成个案判断，不必凑齐样本或强行生成画像。

## 把一段反馈还原成一次选择

以能解释一次选择的语义片段为记录单位；同一个人可以有多个事件，同一个事件也可能出现在多个渠道。保留必要上下文，避免把几个人的话拼成一条「典型原话」。能可靠关联时沿用已有匿名受访者／事件标识；无法确认跨平台身份时标记未知，不猜测去重。

按本次问题选用字段，空缺保留为未知：

| 记录 | 需要保留的内容 |
| --- | --- |
| 定位与对象 | 原始记录ID、匿名对象／事件ID、日期、段落或时间戳、平台及产品版本；身份信息只记录已知且与问题相关的部分 |
| 原话与语境 | 原文；提问或前后文；主动提及还是被提示后回答。转录不清处保留疑点，归纳转述不加引号 |
| 选择经过 | 当时场景、需求触发、想完成的事、考虑过的替代方案（含不买／继续原做法）、障碍与取舍、后续结果 |
| 证据性质 | 本人自述、现场观察、交易／工单记录、他人转述分别标记；「他说买了」仍属于自述 |
| 分析备注 | 暂定主题、研究者解释、冲突材料、缺失环节和可追问问题，与原话分开 |

评论适合识别公开表达与使用线索，客服记录适合还原问题及处置，访谈适合追问选择过程；各自的招募、发声与留存机制会遗漏不同的人。按决策寻找信息，不给渠道预设固定可信度名次，也不默认只取强烈负面或高价值客户。

## 综合时保留差异

先按本次需要解释的选择归组，再比较哪些场景与约束使结果相同或相反。主题应能连接证据与动作，例如「工作日赶时间时，取货等待影响继续购买」；「体验不好」不足以解释问题。主题名是研究归纳，不能当作消费者逐字表达。

检查支持片段之外的材料：同样遇到障碍却继续购买的人、没有遇到障碍却放弃的人、正面与中性反馈。拆开真实分群差异、时间变化、问题诱导和记录缺失；证据无法区分时保留竞争解释。对同一人不同时点的自述差异，先还原时间与场景，不直接判定其言行矛盾。

需要计数时同时交代统计对象与分母：片段数、事件数、独立受访者数各自回答不同问题。重复工单不增加独立人数；仅对实际可识别对象去重。可以写「本次访谈的12人中有4人提及」，不能据此写成「三分之一消费者都有此需求」。情绪强度、提及次数与问题严重性分别判断，不机械相乘成机会分数。

为影响决策的主题保留代表性原话、关键反例、成立条件和最小验证。停止补样本看新增材料是否仍改变机制解释及当前决策，不能用固定访谈次数宣称饱和；受资源限制停止时说明未覆盖人群。

## 示例：取货时间与产品偏好

以下为虚构教学材料：

> I07，访谈03:12：「上周赶着回公司，看到前面还有六单，就换到隔壁了。平时不赶时间我还是买这家。」

原话可支持「该受访者自述一次赶时间时因排队改选」，不能确认真实等待分钟数，也不能推出产品吸引力下降。暂定解释是时间约束下替代门店更有优势；需要找同类场景的继续购买者，或核对排队与取单记录，才可能区分等待、价格和门店便利等解释。

输出给业务的可行方向是先核查高峰等待与取单信息是否可改善。输出给PR的材料保留为局部体验线索，不能直接包装成普遍用户需求或已改善结果。

## 交付压缩

沿用现有洞察链：观察→解释→业务含义→行动→下一步验证。只为会改变判断的主题补充原话定位、反例与范围；底稿可附后，不要求每份报告铺开完整编码表。交给下游时携带这些边界，原话的生动程度不能替代证据强度。


## 评论含义与动作错配：教学例子

以下由初五录音中的假设情境整理，未作为真实消费者案例验证。用于检验解释是否足以支撑动作，不预设例子中的任何解释已成立。

| 原表达 | 不足以直接支持的动作或结论 | 值得区分的原因与补证 |
| --- | --- | --- |
| 给同事点，不知道怎么选 | 增加SKU就能解决 | 同事偏好未知、产品区别不清、替人选择的责任顾虑；追问具体一次选购及比较对象 |
| 单杯券后不贵，凑起送价要多买 | 再发单杯券就够了 | 核对整单支出、起送门槛与不需要的加购，不能只测单杯价格 |
| 太甜 | 消费者健康意识普遍提升 | 核对具体口味、糖度选项理解、跨品牌参照及本人习惯变化；宏观趋势需要另外的证据 |

评论缺少未购者经历时，按研究问题补其他来源或访谈，不为凑固定条数把无法获得的放弃行为编成评论；采集数量和主题频次都不能替代机制验证。
