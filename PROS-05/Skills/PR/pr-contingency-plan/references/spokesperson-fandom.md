# 代言人 / 粉圈预案

适用：明星 / 达人代言、IP 合作。围绕本次合作的对象、物料和风险选择研究深度；已有充分材料时直接判断，不规定生态研究的篇幅。

## 按任务选择模块

以下模块按相关性取用。只对会改变判断的证据缺口补查，不因合作类型强制开展完整人物史或全平台测绘。

## 分步结构

### 1. 合作背景与目标
先明确主要目标，再检查什么条件会影响这次合作。涉及效果预期、权益、货盘或履约时，按需读取`Domains/PR/35-Frameworks/Framework_Celebrity-Partnership-Conditions.md`，把会改变建议的条件带回预案。材料足够时直接判断，不把合作评估扩成销量预测或完整研究。

重点核对品类与价格、合作窗口、授权主体和实际可用权益、购买及售后安排。报价不能只比代言费，头衔不能代替权益；缺少材料保持主Skill的证据不足状态。

### 2. 粉圈生态测绘
给不懂粉圈的人补课，但每段落点都是「所以风险在哪」。覆盖：
- **平台分布与用法**——粉丝主要在哪、各平台干什么用。
- **内部结构**——核心（粉头 / 站姐）、次核心（小组管理）、散粉，各自的话语权和行为模式。
- **动员机制**——靠什么话术 / 约束动员，短期爆发力有多强。
- **CP / 唯粉等派系**——派系矛盾是品牌物料最常踩的雷区。

写法：像科普，但每条都回答「这对品牌意味着什么风险」。

### 3. 合作对象风险档案
按本次风险选择必要的合作史、近期公众事件、公开形象或粉丝语境。写法：每条都要回答「这对品牌意味着什么」——光罗列经历没用，要落到风险或机会。

### 4. 敌对方与恶意图谱
竞争格局（同代竞品、对家）、常见黑梗、敏感词、黑粉构成与行为。写法：把雷标清楚，免得物料无意识踩中。敏感词单列成表，供物料审核直接比对。

### 5. 核心关注点收敛
把一大堆可能的雷，收成几条能记住的。代言类常见的核心关注点：粉丝情感需求没被满足（背刺、不尊重）、品牌执行细节失误、代言头衔不匹配、对家粉丝干扰。再定几条宣传红线（不碰哪些词、不提哪些人 / 哪些过往）。写法：这一步最见功力——预案做厚不难，收成几条能执行的判断才难。

### 6. 全周期分阶段风险
按当前项目覆盖准备、预热、官宣、日常维护和合作结束；核对商品页、客服、门店与物料是否同步，以及权益、库存、配送和后续服务是否有人负责。结束时检查素材使用和未完成消费者事项。写法：按阶段列有具体依据的重点风险，连接触发、依据、动作与责任缺口；对未来行为的推演标为假设。内部按主Skill四态记录，已检查未发现的阶段不凑风险，未获得关键素材的阶段标为证据不足。

### 7. 次生风险
按具体依据判断行程泄露、名额或周边倒卖、素材使用争议及品牌内部执行问题，不预设都是粉丝造成的。收到投诉先核实产品、规则和履约；消费者的粉丝身份不能成为把合理投诉归为恶意的理由。有据造谣另行记录出处、核验状态和处置，不用措辞调整替代实际服务。

### 8. 应对口径与执行建议
官方文案的统一口径（聚焦代言人个人、照顾主要粉群情绪、避开派系雷区）、特殊情况的处理通路（与艺人团队 / 内容 / 公关三方对口径）。写法：把前面所有判断收成几条品牌方真能做的动作。

## 重心提醒
生态研究只覆盖本次合作会接触的角色和机制；把有依据的风险收成可执行边界。需要长期跟踪时交付监测建议与触发条件；只有用户授权持续监测时才创建运行任务。
