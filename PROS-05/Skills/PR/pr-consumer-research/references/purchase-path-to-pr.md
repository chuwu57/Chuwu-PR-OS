# 购买路径与售后结果的PR转换

用于已有购买路径、搜索、传播内容、内容／货架、低频消费、文化趋势或售后证据需要转成PR动作的任务；复用上游研究，不为这一转换自动重新采样。事实、信号、解释及公开边界沿用主Skill。

没有明确业务影响时，PR动作保持克制。只有需要把相关研究转成传播任务时才展开下文。

涉及品牌信任或目标人群时，复用研究方对公众、品类消费者、品牌消费者的分层结果；不能把一层的疑问或认可外推给全部人群。需要补充设计时按[人群层次与细分粒度](../../../Research/consumer-research/references/research-context.md)处理，已有证据足够时直接限定主张并给出动作，不重跑研究。

## 根据实际障碍确定传播任务

下表是候选对应关系，选用前检查证据和业务条件，不默认所有环节都有问题：

| 证据指向的环节 | 可考虑的传播支持 | 需要业务先确认的条件 |
| --- | --- | --- |
| 尚未产生兴趣或理解需求 | 具体使用场景、产品价值演示 | 产品是否解决该场景的问题，信息能否到达相关人群 |
| 有需要时未想到品牌 | 可识别且与场景相关的表达 | 是否确为记忆问题，不能把买不到误判为没想到 |
| 想买但难以找到或到达 | 准确的搜索信息、门店或购买指引 | 库存、覆盖与入口是否真实可用 |
| 不理解、不相信或难以比较 | 可核验说明、演示与对应证据 | 差异与承诺能否兑现，避免只换一种更强的说法 |
| 优惠、起送门槛或履约阻碍成交 | 解释已确认且可执行的规则 | 规则、价格或交付本身是否需要调整，说明不能消除实质障碍 |

内容、搜索、门店和直播可共同影响一次购买。同一卖点的表达取决于消费者当时要完成的判断；不按平台名称固定话术，也不把内容型或货架型作为品牌永久标签。只有证据表明某端短板限制目标、且业务能力允许时，才建议补充该端资源。

每项建议连接已知障碍、目标对象、需要帮助的判断、可用事实、业务依赖与观察结果。缺口影响动作时保留条件或最小补证；已有证据足够时直接完成PR判断。不要由接触、点击或最后成交入口单独认定传播增量。

## 搜索与内容结果的转换

复用上游对信息缺口、理解偏差和后续选择的判断，区分信息呈现、消费者采用与业务贡献。反复搜索可能是疑问未获解答，搜索减少也不能单独证明优化成功；一次AI回答提及品牌不支持消费者偏好或ROI。只有需要补充对应研究时，才读取[搜索过程](../../../Research/consumer-research/references/search-process.md)，不为普通事实转换增加研究。

内容建议应说明目标对象、希望改善的理解或选择，以及可能的注意、信任或品牌记忆取舍。受众反映服务与宣传不符时，核验实际经历和执行，不能全部归为表达误会。已有研究足够时直接限定主张并给出动作；缺口影响内容决策时才读取[传播内容与效果](../../../Research/consumer-research/references/communication-content-effects.md)。公开表述与具体文案继续使用主Skill及已有专项门禁。

B端与C端材料互用时，按[内容转用的角度与成本](../../../../Domains/PR/35-Frameworks/Framework_Content-Penetration-Loop.md)识别新对象要回答的问题、可复用事实、补证要求和制作／分发能力。研究结论、技术说明、用户故事的证据强度保持不变；材料是否值得转用取决于业务目的和增量投入，不默认每份材料都产出两个版本。

## 低频消费与文化趋势的转换

复用上游对品类需要、品牌选择和场景变化的判断。只有障碍涉及记忆、理解或信任时，才优先考虑相应传播；渠道、规格、价格及履约问题交接给能够改变条件的业务环节，传播可支持已确认的信息与指引。维护有限购买或暂不增频也可以成为建议，不能从本品牌低频直接推出品牌好感下降，或自动把资源转向新客。缺口会改变动作时才读取[低频消费研究](../../../Research/consumer-research/references/low-frequency-and-occasions.md)。

文化与趋势材料先转换成有对象、有场景、有事实支持的议题或方案，不能把热门标签扩大为整个人群的共同价值观，也不能把平台声量写成需求规模。产品、服务与组织能力需能够支撑拟采用的主张；AI推演只提供假设。已有研究足够时直接完成PR判断，仅在关键缺口影响行动时读取[文化与趋势研究](../../../Research/consumer-research/references/consumer-culture-and-trends.md)。公开边界与具体文案继续沿用主Skill及已有专项规则。

## 售后动作与体验主张

把事件事实、组织处理动作、消费者实际结果和长期信任分别表达。结单、退款、响应加快只能直接证明相应动作；体验恢复需要问题解决、承诺兑现或其他对应结果，长期信任仍需自身证据。不能把沉默当满意，也不能用投诉减少单独证明品质提升。

优先复用研究方对事件、剩余损失与统计口径的结论。需要自行补充售后分析时才读取[售后经历与解决结果](../../../Research/consumer-research/references/after-sales-experience.md)。已知仍有真实损失时，将必要整改与可公开事实一起交接；风险排序考虑伤害、范围、紧迫性及可改善程度，不单按情绪或声量。
