# judgment-hub 知识调用地图

## 任务输入：复用已有交接

已有专项分析通过八字段交接包进入；缺失专项能力时按[Skill入口](../SKILL.md)路由，不在知识地图重复维护一份Skill清单。交接包提供本次事实和已完成分析，专业判断权威来自下列知识资产；冲突时校准具体结论，避免把一次输出当成长期原则。

## 按需理论校准

理论只用于校准判断，不直接写成答案主轴。

- 先从[跨学科问题链](../../../../Domains/PR/15-Theory/00_Problem-Chains/README.md)按真实问题进入，再回到相应理论专论核验机制和边界。
- 传播学总入口：[传播理论到PR判断](../../../../Domains/PR/15-Theory/Communication/00_MOC/传播理论到PR判断.md)，用于区分注意、意义、媒体／平台、公众关系、危机风险与扩散机制。
- 心理学按机制进入：[注意](../../../../Domains/PR/15-Theory/Psychology/10-Attention-and-Limited-Capacity/有限注意与工作记忆.md)、[理解](../../../../Domains/PR/15-Theory/Psychology/20-Comprehension-and-Gist/情境模型与要旨表征.md)、[责难](../../../../Domains/PR/15-Theory/Psychology/30-Attribution-and-Blame/责任归因与责难形成.md)、[信任](../../../../Domains/PR/15-Theory/Psychology/40-Trust-and-Repair/信任可信度与修复.md)、[情绪](../../../../Domains/PR/15-Theory/Psychology/50-Emotion-and-Appraisal/情绪评价与行动倾向.md)、[身份](../../../../Domains/PR/15-Theory/Psychology/60-Identity-and-Motivated-Cognition/社会认同与动机性认知.md)、[说服](../../../../Domains/PR/15-Theory/Psychology/70-Persuasion-and-Resistance/说服加工与心理抗拒.md)、[纠错](../../../../Domains/PR/15-Theory/Psychology/80-Misinformation-and-Correction/错误信息记忆纠错与预防.md)与[行动](../../../../Domains/PR/15-Theory/Psychology/90-Intention-and-Action/个体风险与集体行动.md)。
- 社会学总入口：[社会理论到PR判断](../../../../Domains/PR/15-Theory/Sociology/00_MOC/社会理论到PR判断.md)，用于区分制度合法性、定义权、边界与污名、一线实践、风险依赖、网络扩散及公共行动。

## 使用边界

- 不因理论成立就直接建议动作，必须回到事实、业务目标和组织承受能力。
- 不因案例相似就机械套用，必须判断行业、品牌阶段、平台和公众情绪是否相同。
- 不把所有分歧升级成危机；只有影响资产、业务或组织信任时才升级。
